Steel Structural Design

SteelCAD Plugin for AutoCAD

A .NET plugin for AutoCAD that draws parametric steel members: each beam is a smart object with 7 grips, 4 switchable view types and 6 section shapes — plus drawing-markup, RC detailing and anchor-bolt modules.

⤢

Key features

  • <b>Parametric steel members</b>: 7 grips; change section/label/cuts
  • <b>4 view types</b> switched instantly: Plan, Elevation, Section
  • <b>6 section shapes</b>: H/W/I, Box, Pipe, T, C…
  • Moment connections, working-line control, full/short section labels
  • <b>Markup module</b>: connections, grids, notes, section symbols
  • <b>RC drawing module</b>: columns, beams, foundations and foundation elevations
  • <b>Anchor bolts</b> (STEELBOLT) for base-plate details
  • <b>Dockable palette</b> — section browser, drawing scale, text height, text style
