Pile Capacity & Settlement Check

Checks pile capacity against Long-term / Wind / Seismic combination groups, plus differential settlement between every pile pair. Reactions taken live from SAP2000.

⤢

Key features

  • <b>Automatic data input</b>
  • <b>Automatic load-type classification</b> (Long-term / Wind / Seismic)
  • Multiple pile types; kN ↔ Ton switching converts values automatically
  • <b>Piling diagram</b> coloured by pile type or capacity ratio
  • <b>Differential settlement check</b>
  • Excel capacity report (4 sheets) and settlement report (2 sheets)

System requirements

Windows / SAP2000
